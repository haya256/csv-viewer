# csv-viewer

ブラウザだけで動く、シンプルなCSVビューワーです。
`index.html` をダブルクリックで開くだけで使えます。サーバーやインストールは不要です。

## 特徴

- **データは外部に送信・保存されません** — ファイルはブラウザのメモリ内だけで扱い、ページを更新すると消えます。外部ライブラリ・CDNも使わないため完全オフラインで動作します
- **文字コード自動判定** — UTF-8（BOM付き含む）/ Shift_JIS を自動判定。文字化け時はプルダウンで手動切替
- **キーワード検索** — いずれかのセルに部分一致する行だけを表示
- **列条件フィルタ** — 「[列] が [値] [を含む / と等しい / > / 空 など]」の条件を複数（AND）で指定
- **列幅の調整** — 見出し右端のドラッグで幅を変更、ダブルクリックで内容に合わせて自動調整
- **ヘッダー固定** — スクロールしても列名と行番号が常に表示される
- 引用符内のカンマ・改行、`""` エスケープに対応（RFC 4180）
- 大きなファイルは1000行ずつ表示（「さらに表示」で追加）
- `.tsv` ファイルはタブ区切りとして読み込み

## 使い方

1. `index.html` をブラウザで開く
2. 「ファイルを開く」でCSVを選択するか、画面にドラッグ&ドロップ
3. 必要に応じて検索欄・「＋条件を追加」で絞り込み

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `style.css` | スタイル（ライト/ダークモード対応） |
| `app.js` | 読み込み・パース・検索・フィルタ・描画 |
